# v1.10 tuned-lens — validation note

**Date:** 2026-06-07
**Branch:** `claude/latest-version-code-review-CFL8H`
**Scope:** functional validation of the v1.10 tuned-lens feature (CPU). The §10 **GPU**
wall-clock re-validation with `tuned_lens_kl` enabled is still pending a GPU run (see below).

## What was validated (CPU)

1. **The tuned lens beats the logit lens at every layer** — the whole point of the feature. On a
   tiny 4-block decoder whose blocks deliberately rotate/shift the residual stream (so each layer
   lives in a different basis than the final frame), `examples/tuned_lens.py` reports, on a
   held-out batch:

   | layer | logit_lens KL | tuned_lens KL |
   | ----: | ------------: | ------------: |
   | 0     | 0.1255        | 0.0181        |
   | 1     | 0.0878        | 0.0117        |
   | 2     | 0.0351        | 0.0046        |

   The fitted affine translator absorbs the basis mismatch, cutting per-layer KL ~7×. This is the
   qualitative signature the tuned lens is meant to produce (Belrose et al. 2023).

2. **Reduction property** — with `A = I, b = 0`, `tuned_lens_kl` equals `logit_lens_kl`
   bit-for-bit (`tests/core/test_lens.py`), and a translator matching the final frame drives KL→0.

3. **Fit improves held-out KL** — `fit_tuned_lens` produces translators whose held-out KL is
   strictly below the logit lens on a mid layer (`tests/tuned_lens/test_fit.py`).

4. **Recorder / scan integration** — the opt-in `tuned_lens_kl` diagnostic emits
   `activation/tuned_lens_kl/<layer>` per fitted block, warns + skips on a missing lens or a
   fingerprint mismatch (never emits a wrong KL), and leaks no hooks
   (`tests/recorder/test_tuned_lens_diagnostic.py`). It flows through `scan_run` unchanged (shared
   recorder dispatch). The `circuitry fit-tuned-lens` CLI round-trips a loadable `TunedLens`
   (`tests/test_tuned_lens_cli.py`).

5. **Serialization + fingerprint guard** — `TunedLens.save`/`load` round-trips; the
   architecture-sensitive `model_fingerprint` distinguishes a deeper model and is weight-insensitive
   (a fine-tuned copy keeps the same fingerprint).

6. **Full suite** — 647 passed, 26 skipped. The 15 failures are pre-existing missing-optional-dep
   tests (tensorboard / sae-lens / transformer_lens / torchvision not installed in this env), not
   regressions.

## Pending (GPU)

- **§10 wall-clock budget with `tuned_lens_kl` enabled.** Not yet measured on GPU. The diagnostic
  reuses the captured block outputs (no extra forward pass) and adds one `(d_model × d_model)`
  matmul + bias per layer per emit on top of the logit-lens projection it sits beside, so it is
  expected to stay within the ≤10% budget — but this should be confirmed on the same RTX 5080 / 88M
  decoder harness used for v1.9 before claiming the budget holds. Tuned-lens *fitting* is post-hoc
  and outside the training-loop budget by design.
- **Real-model fit (GPT-2-small).** A fit + diagnostic run against a real pretrained model
  (validating residual/unembed/final-LN resolution on a real HF architecture) is deferred to a GPU
  host with `transformers` installed.
